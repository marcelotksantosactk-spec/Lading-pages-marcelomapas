O acesso é liberado automaticamente assim que o pagamento é reconhecido. Você recebe um e-mail com o link para baixar o PDF.

Posso imprimir?

Sim. O PDF tem download ilimitado e está liberado para impressão durante todo o período de acesso.

Serve para qualquer prova que cobre Português. O conteúdo é a matéria em si, não um edital específico.

Posso dividir com um amigo?

Não. O material é protegido pela Lei de Direitos Autorais (Lei nº 9.610/98). A compra é individual.
