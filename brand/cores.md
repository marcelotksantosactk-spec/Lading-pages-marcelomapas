# Paleta de cores

## ⚠️ Status

Paleta provisória extraída do estilo visual do documento-base (`projeto_producao_digital_skills.html`) — um tema escuro (dark navy) com acentos azul e verde-menta. Troque pelos valores oficiais da marca assim que existirem.

## Paleta base (dark)

| Papel | Cor | Hex | Uso |
|---|---|---|---|
| Fundo principal | Azul-marinho quase preto | `#0b1020` | Fundo de página, seções escuras |
| Painel / card | Azul-marinho | `#121a2f` | Cards, blocos de conteúdo |
| Painel secundário | Azul-marinho claro | `#18223d` | Variação de card, hover |
| Texto principal | Quase branco | `#eef3ff` | Títulos e corpo de texto sobre fundo escuro |
| Texto secundário | Cinza-azulado | `#aeb8d0` | Parágrafos, legendas |
| Borda | Azul-acinzentado | `#2a365b` | Bordas de cards, tabelas, divisores |
| Acento primário | Azul | `#7c9cff` | Links, CTAs secundários, ícones de destaque |
| Acento secundário | Verde-menta | `#8ef0c7` | Destaques positivos, notas, sucesso |
| Alerta | Amarelo | `#ffd166` | Avisos, atenção |
| Erro / crítico | Vermelho suave | `#ff7b7b` | Erros, pegadinhas, pontos de atenção em questões |

## Regras de uso

1. **Contraste primeiro**: texto principal (`#eef3ff`) só sobre fundos escuros (`#0b1020`, `#121a2f`, `#18223d`). Nunca usar texto claro sobre acento claro.
2. **Acento primário (`#7c9cff`) é para ação e destaque**, não para grandes áreas de fundo.
3. **Verde-menta (`#8ef0c7`) marca acerto/positivo**; **vermelho (`#ff7b7b`) marca erro/atenção/pegadinha** — manter esse significado consistente em questões comentadas e mapas mentais.
4. **Amarelo (`#ffd166`) é reservado para avisos** (ex.: "não pule etapas"), não para decoração.
5. Landing pages de venda podem usar uma variação **light** derivada da mesma paleta (fundo claro, mesmos acentos), desde que o contraste mínimo AA seja mantido — a decidir quando houver a primeira landing page real.

## Paleta por aplicação

| Aplicação | Cores principais |
|---|---|
| Mapas mentais | Fundo escuro + acento azul para ramos principais + verde-menta para exemplos |
| Resumos ilustrados | Fundo claro ou escuro (definir por produto) + azul para conceitos-chave + amarelo para avisos |
| Questões comentadas | Verde-menta para "correto", vermelho para "incorreto/pegadinha" |
| Landing pages | Fundo escuro (identidade) + CTA em azul ou verde-menta, nunca os dois competindo na mesma tela |
